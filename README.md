# After Bell for Mac

Native macOS homework tracker. SwiftUI + SceneKit. Not an iPhone app.

## Open in Xcode

1. Click the green **Code** button on this page → **Download ZIP**.
2. Unzip.
3. Double-click **AfterBell.xcodeproj**.
4. If Xcode asks to Trust, choose Trust.
5. Set the destination to **My Mac** (not a phone).
6. Press Play, or Command-R.

Needs macOS 14+ and Xcode 15+. First compile takes a minute.

Homework is saved on this Mac in Application Support/AfterBell.
